# Notice

**Xiaohei Illustrations** is an English Claude Code adaptation of **Ian Xiaohei Illustrations**, an AI-agent skill created by Ian for Chinese article illustrations.

- Original (Codex skill, Chinese): <https://github.com/helloianneo/ian-xiaohei-illustrations>

## What changed in this adaptation

- Translated all skill instructions and references from Chinese to English.
- Converted the skill format from OpenAI Codex (`SKILL.md` + `agents/openai.yaml`) to a Claude Code skill (`SKILL.md` with a trigger-oriented `description`); the Codex-specific `agents/openai.yaml` was dropped.
- Switched the generated illustrations' handwritten labels to **English** and removed the Chinese-article focus.
- Made image generation **tool-agnostic**: the skill calls whatever image-generation tool is available, or falls back to a planning-only mode, since Claude Code has no built-in image generator.
