# Composition patterns & the originality rule

## Base structure types

Pick one; don't blend too many.

### Workflow

For: input → process → output, content production, AI workflows, automation chains.
Draw: input on the left, Xiaohei or a weird machine processing in the middle, output on the right, orange arrows for the main direction.

### System fragment

For: information sources, filters, databases, renderers, a slice of an agent system.
Draw: only 3–5 core modules; Xiaohei involved in one key action.

### Before / after

For: messy/ordered, manual/automatic, scattered/converged, anxious/steady.
Draw: chaos left, calm right, orange arrow between. The character can be more exaggerated.

### Character state

For: user pain, creator state, too-many-tools, info anxiety, stuck → running.
Draw: 2–4 small states, one short label each.

### Concept metaphor

For: content factory, info warehouse, mental black box, workflow machine, automated daily report.
Draw: one big weird object or machine, a little input, one output. Make it memorable.

### Layered method

For: methodology frameworks, system layers, capability stacks, content-system tiers.
Draw: stacked boxes (not a formal pyramid); Xiaohei carrying bricks or building beside it.

### Map / route

For: idea → launch, user path, content handoff path, learning route.
Draw: one winding path, a few nodes, Xiaohei pulling a string or walking it.

### Mini comic

For: failure → success, the real process, a gripe, before/after use.
Draw: 2–4 small panels, one action per panel.

## How to invent a fresh metaphor

Reinvent the metaphor from the current article every time; never reuse an old figure.

### Three steps

1. Turn the abstract concept into a **physical action**: stuck, leaking, getting heavier, sorting, settling, fermenting, opening, folding, unpacking, flowing back.
2. Turn the system structure into a **low-tech object**: a broken machine, cardboard box, drawer, pipe, mailbox, weird dial, scale, well, ladder, odd workstation.
3. Let **Xiaohei carry the action**: not standing aside — stuck in the machine, pulling the wrong string, guarding a gate, hauling, patching, weighing, holding the ladder, logging, stuffing something into a strange contraption.

### Object pool

- Cardboard box, drawer, old machine, funnel, scale, mailbox, door, well, ladder, pipe, ball of string, sluice gate, turntable, black box, hole-punch, pasta press, clothesline, odd workstation.
- Use only 1–2 at a time; don't pile them up.

### Xiaohei action pool

- Pull, haul, stuff, scoop, press, weigh, sew, cut, twist, guard, push, catch, unpack, tag, recycle.
- The action must serve the core meaning — don't be weird for weird's sake.

## Anti-replication rule

Don't open or copy `examples/images/` by default. Those are for **style calibration only** — line density, white space, color restraint, Xiaohei's vibe.

Unless the user explicitly says "like this one / replicate this composition / edit this case", don't reuse these known compositions:

- Conveyor belt with two breakpoints
- Xiaohei pulling a judgment lever inside a content machine
- Xiaohei as a funnel sorting traffic / trust / conversion
- Xiaohei slicing a material fish
- Xiaohei leading a handoff path
- Xiaohei pulling three layers of sources
- Three Xiaoheis holding a megaphone / building a bridge / opening a door
- Xiaohei stamping a copy toolbox
- Xiaohei holding a sign over a common-pitfalls path

Use a fresh metaphor even for the same kind of topic. E.g. a "handoff path" needn't be a route — it could be Xiaohei hooking the tail of one piece of content onto a doorknob; "one source, many uses" needn't be a fish — it could be Xiaohei pressing one paper ball into several shapes.
